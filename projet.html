1. Pipelines robustes & monitorés

📉 Dashboard vide

“Plus aucune vente affichée”

Gestion schéma (price vs unit_price)

✔ Pipeline résilient

❌ Avant
df["price"]

⚠️ Problème
Colonne renommée → pipeline cassé

✅ Après
price = df.get("price", df.get("unit_price"))

⏱ Données incomplètes

“Chiffres faux”

Late data + incrémental

✔ Décisions fiables

❌ Avant
df = df[df.date == today]

⚠️ Problème
Données arrivent en retard

✅ Après
df = df[df.date >= today - 3]

🔁 Duplication

“Données doublées”

Idempotence

✔ Données propres

❌ Avant
INSERT INTO table SELECT * FROM staging

⚠️ Problème
Re-run = doublons

✅ Après
MERGE INTO table USING staging ON id

💥 Crash volume

“Pipeline plante”

Chunk processing

✔ Scalabilité

❌ Avant
df = pd.read_csv("big.csv")

⚠️ Problème
Out of memory

✅ Après
for chunk in pd.read_csv("big.csv", chunksize=10000):
    process(chunk)

🌐 API instable

“Données absentes”

Retry logique

✔ Résilience

❌ Avant
requests.get(url)

⚠️ Problème
Timeout API

✅ Après
retry(3):
    requests.get(url, timeout=5)

2. Automatisation

👨‍💻 Script manuel

“Quelqu’un doit lancer le job”

Orchestration automatique

✔ Fiable

❌ AVANT
python pipeline.py

⚠️ PROBLÈME
# dépendance humaine → oubli possible

✅ APRÈS
# cron (tous les jours à 2h)
0 2 * * * python pipeline.py

⚙️ Paramètres en dur

“Impossible de rejouer facilement”

Paramétrisation CLI

✔ Flexible

❌ AVANT
date = "2024-01-01"

⚠️ PROBLÈME
# modification manuelle du code nécessaire

✅ APRÈS
import argparse
parser = argparse.ArgumentParser()
parser.add_argument("--date")
args = parser.parse_args()

3. Données propres & normalisées

⚠️ NaN

“KPI incohérents”

Gestion explicite des nulls

✔ Fiabilité

❌ AVANT
df["revenue"].mean()

⚠️ PROBLÈME
# présence de NaN → biais

✅ APRÈS
df["revenue"].fillna(0).mean()

📅 Dates incohérentes

“Analyses fausses”

Normalisation

✔ Cohérence

❌ AVANT
"01/02/2024"

⚠️ PROBLÈME
# format ambigu (US vs EU)

✅ APRÈS
pd.to_datetime(col, format="%d/%m/%Y")

4. Performance & coûts

🐢 Pipeline lent

“Traitement trop long”

Vectorisation

✔ x50

❌ AVANT
for i in range(len(df)):
    df.loc[i, "x"] = df.loc[i, "a"] * 2

⚠️ PROBLÈME
# boucle Python lente

✅ APRÈS
df["x"] = df["a"] * 2

5. Structuration & documentation

🧾 Noms flous

“Incompréhensible”

Nommage métier

✔ Lisibilité

❌ AVANT
df["col1"]

⚠️ PROBLÈME
# aucune signification

✅ APRÈS
df.rename(columns={"col1": "total_sales"})
